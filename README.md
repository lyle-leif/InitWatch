# InitWatch

**A heat-action and buddy check-in system for outdoor workers.**
*Walang maiiwan sa init. No worker left unchecked in the heat.*

This repository holds the web presentation of the InitWatch project proposal by Team 16: Alvarez, John Allen · Bantayaon, Jeush Samuel L. · De Galicia, Phebe A. · Esguerra, Lyle Daniel · Ordiales, Samuel.

**Live deck:** https://lyle-leif.github.io/InitWatch/

## Presenting

The whole deck is one file, `index.html`. Open it in a browser, online or offline (fonts load from Google Fonts when online).

| Key | Action |
|---|---|
| Scroll, ← → ↑ ↓, Space | Next / previous slide |
| O | All slides |
| N | Speaker notes |
| F | Fullscreen |
| Esc | Close notes or overview |

On phones and portrait tablets the deck becomes a scrolling page.
